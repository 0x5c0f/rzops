## 三、发现的问题

### 🔴 高优先级

#### BUG-1：多选下拉（FormMultiSelect）已选标签的"×"移除按钮点击无效【已修复】

- **位置**：`rzops-web/src/lib/components/shared/FormMultiSelect.svelte`（所有使用该组件的多选下拉）
- **影响范围**：供应商类型、服务器"角色标签"、服务器"Web服务器软件"、数据中心"线路类型"（4 处）
- **现象**：已选值以 Badge 标签展示并带"×"移除按钮，但**真实鼠标点击"×"无效**（值不移除、需先打开下拉再点"已选（点击取消）"）；程序化 `el.click()` 却正常。
- **根因**：bits-ui `Select.Trigger` 在 **pointerdown 阶段**即打开浮层（popover），浮层弹出覆盖原点击位置，吞掉了后续 `click` 事件，Badge 上 `onclick` 的 `removeValue` 不会触发。
- **修复**：Badge 移除按钮增加 `onpointerdown` 处理（`stopPropagation + preventDefault + removeValue`），在 pointerdown 阶段拦截并移除值，同时保留 `onclick`/`onkeydown` 兜底。
- **验证**：修复后点击"移除 域名"的"×" → 值从 `ISP 域名` 变为 `ISP`，下拉未误展开；已同步重建 8081（测试）与 8080（用户环境）。
- **说明**：供应商类型**多选为产品设计**（用户确认），非缺陷；多选值详情页以逗号连接展示正常。

### 🟡 观察项（建议优化，非阻塞）

#### OBS-1：只读角色访问已授权页面时，参考数据接口 403 报错

- **现象**：`e2e`（只读角色）访问有权限的业务页面时，页面依赖的参考数据接口被拒：
  - 证书页面 → `permission 'dict:read' required`（证书类型字典）
  - 数据中心/备份计划等 → `permission 'provider:read' required`（供应商下拉）
  - 控制台大量 403 错误；页面上相关下拉/选项为空
- **原因**：页面公共组件（字典选项、供应商下拉）使用独立的 `dict:read` / `provider:read` 权限，与业务菜单权限未对齐。
- **建议**：只读类角色默认授予 `dict:read` 等参考数据权限；或页面加载参考数据失败时静默降级（下拉显示空态而非报错）。

#### OBS-2：错误提示未汉化

- "data center not found"、"forbidden: permission 'xxx:read' required" 等后端错误信息直接透传到前端 Toast/页面。
- **建议**：API 层统一映射中文提示（如"数据中心不存在""无访问权限"）。

#### OBS-3：审计/变更日志"资源类型"部分显示英文

- 审计日志与变更记录中，`role`、`dict`、`data_center`、`certificate_domain` 等资源类型未汉化（服务器/数据中心等为中文，风格不一致）。
- **建议**：统一维护资源类型中文映射。

#### OBS-4：供应商详情"关联服务器"表中服务器类型列未翻译

- 供应商详情 → 关联服务器表格，"服务器类型"列显示字典值 `physical`（列表页已汉化为"物理机"）。
- **建议**：关联表复用与列表页一致的字典翻译。

#### OBS-5：数据库实例状态不随关联服务器退役联动

- 服务器 e2e-srv-web-01 退役后，关联的数据库实例 e2e-db-main 状态仍显示"运行中"（列表有"(已退役)"后缀提示，但实例自身状态未变）。
- **说明**：历史已评估该联动会引入复杂性，当前为"不联动"设计，**待产品决策**是否在实例状态上体现。

#### OBS-6：删除数据后访问旧详情 URL 显示英文 404

- 彻底删除数据中心后，直接访问其旧详情 URL → 页面提示 "data center not found"（英文 + 无返回引导）。
- **建议**：404 时提供"返回列表"引导并汉化提示（全局 404 页已存在，详情级 404 可复用）。

## 五、待人工复核项（自动化覆盖不足，建议人工抽测）

1. **附件下载**：浏览器下载文件的真实内容与字节数（自动化已确认上传/列表/下载入口，未展开文件内容比对）
2. **复杂组合筛选**：多条件（类型+环境+状态+数据中心）同时筛选的组合结果
3. **大数据量性能**：万级服务器/端口/IP 下列表渲染与筛选响应（当前仅测试数据规模）
4. **并发操作**：多用户同时编辑同一资源、快速连续 F5（历史问题：会话偶发失效，需关注）
5. **键盘可达性**：纯键盘 Tab 导航、弹层 ESC 关闭（历史已确认 ESC 正常）
6. **多浏览器兼容**：Firefox/Safari（当前仅 Chrome）
7. **端口多服务器绑定**：单端口绑定 3+ 台服务器时列表"+N"缩减与详情全量展示（当前测试数据仅 1 台）
