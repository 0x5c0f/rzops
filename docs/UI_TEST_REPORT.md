## 三、发现的问题（按严重度排序）

### 🔴 严重（数据丢失风险）

#### BUG-1：编辑页枚举字段（状态/环境）回显丢失，保存后数据被清空

- **位置**：`ServerForm.svelte`、`DatabaseInstanceForm.svelte`、`OpsSiteForm.svelte`（环境字段）等所有表单
- **现象**：
  1. 服务器编辑页：状态字段显示"请选择"（应为"运行中"）、环境显示"选择环境"（应为"测试"）；**此时点保存，状态会被提交为空**，列表状态列变空——实测 e2e-test-srv-01 状态已被清空；
  2. 数据库实例编辑页：环境显示"选择环境"（创建时选的"测试"）；
  3. 站点编辑页：环境显示"选择环境"（创建时选的"生产"）。
- **影响**：用户仅修改任意字段点保存，未回显的枚举字段即被清空 → **存量数据损坏**。这是目前最严重的问题。
- **复现路径**：服务器列表 → 编辑 e2e-test-srv-01 → 查看状态/环境 →（保存）→ 返回列表看状态列。
- **建议**：表单 initialSnapshot → createInitial 映射补全 status/environment 等枚举字段（参照服务器选择器已修复的 displayOptions 模式），并补保存前"未修改字段不提交/提交原始值"的保护。

---

### 🟠 中等

#### BUG-2：列表高级筛选的"服务器"选择器（RemoteSearchSelect）点击选项无效

- **位置**：`server-ips/+page.svelte`（247-252 行）、`database-instances/+page.svelte`（272-278 行）等所有列表页高级筛选
- **现象**：高级筛选面板中，服务器下拉（RemoteSearchSelect）点击"e2e-test-srv-01"选项后，触发器仍显示"全部服务器"，已选条件不出现，筛选不生效。
- **关键对比**：**表单里的同款组件点击正常**（数据库实例新建、备份计划目标对象、合同供应商均成功）——组件本身无问题，问题在列表页筛选的绑定/事件上下文。
- **影响**：服务器维度的筛选在所有列表页失效（用户之前已反馈过"筛选下服务器搜索未生效"）。
- **建议**：对比表单页与列表页的 `bind:value` 用法；排查 `{#if}` 条件渲染容器内事件委托 + `query` 对象整体替换导致响应式丢失的问题。

#### BUG-3：服务器端口表单的服务器选择为单选，与"端口支持多服务器绑定"需求不符

- **位置**：`ServerPortForm.svelte`（TableSelectModal `multiple={false}`，保存只取 `server_ids[0]`）
- **现象**：端口表单"选择服务器"弹层为单选（点击第二行会替换已选）；提交仅保存第一个服务器 ID。而需求是端口可绑定多台服务器（列表也按多服务器 +N 展示）。
- **复现路径**：服务器端口 → 编辑/新建 → 选择服务器弹层 → 尝试多选。
- **建议**：`multiple` 改 true，保存提交完整 `server_ids` 数组。

#### BUG-4：详情页顶部状态徽章映射错误

- **位置**：数据中心/证书/服务器详情页（`[id]/+page.svelte` 状态徽章）
- **现象**：
  - 数据中心详情徽章"运行中"（基本信息卡显示"活跃"）；
  - 证书详情徽章"运行中"（卡显示"有效"）；
  - 服务器详情徽章"数据库服务器"（勾选 is_db_server 后徽章显示该值，而非状态）。
- **影响**：状态信息展示矛盾，误导运维。
- **建议**：统一状态徽章映射表（各资源用各自状态枚举 + 颜色）。

### 🟡 较低

#### BUG-5：服务器/站点详情页缺"环境"字段

- **现象**：服务器详情基本信息无"环境"；站点详情基本信息无"环境"（列表有环境列、编辑页有环境字段）。
- **建议**：详情页补充环境展示。

#### BUG-6：审计日志"资源"列对新建记录显示 "-"

- **现象**：审计日志列表/详情的资源列显示 "-"（变更记录同款场景能显示资源名如 e2e-test-cert）。
- **建议**：审计记录回填资源名称（与变更记录一致）。

#### BUG-7：只读用户详情页仍可见"删除"按钮（删除附件）

- **现象**：只读访客 e2e-viewer 在服务器详情页可见附件条目后的"删除"按钮，可删除附件。列表页新建/编辑/删除已正确隐藏。
- **建议**：详情页附件删除按钮同样按权限控制（viewer 不可见）。

#### BUG-8：只读用户菜单无"审计"入口（待确认）

- **现象**：viewer 角色描述为"所有资源只读，仅可查看"，但登录后菜单没有"审计"（审计日志/变更记录），而字典/附件可见。
- **建议**：核对 viewer 角色权限配置中审计菜单是否勾选；如配置如此，更新角色描述或补权限。

1. **TableSelectModal 复选框双重 toggle**：checkbox `onchange` 与所在行 `tr onclick` 都会调用 `toggleRow`，点击 checkbox 时先触发 change 再冒泡到 tr → 两次 toggle 互相抵消（选中变未选中）。修复：checkbox 增加 `onclick={(e) => e.stopPropagation()}`，行点击走 tr、checkbox 走自身 change。
